# AgentFarm

AgentFarm is a web-based platform for managing and orchestrating AI agents. It provides a simple interface to create, monitor, and control multiple AI agents with different specializations.

## Features

- Create and manage multiple AI agents
- Different agent types (Assistant, Researcher, Coder, Custom)
- Start/stop individual agents or all agents at once
- Monitor agent status and activities
- Simple and intuitive user interface

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Use the interface to create and manage your AI agents

## How It Works

AgentFarm provides a dashboard where you can:

- View all your created agents
- Add new agents with specific types and descriptions
- Start and stop agents individually or all at once
- Delete agents you no longer need

The current implementation simulates agent activities with console messages. In a real-world application, these agents would perform actual tasks like answering questions, researching topics, or writing code.
