# AgentFarm

AgentFarm is a web-based platform for managing and monitoring AI agents. It provides a simple interface to create, start, stop, and delete various types of AI agents.

## Features

- Create custom AI agents with different types and descriptions
- Start and stop individual agents
- Start and stop all agents at once
- Delete agents
- Responsive design that works on desktop and mobile devices

## Getting Started

To use AgentFarm, simply open the `index.html` file in a web browser.

```bash
# Clone the repository
git clone https://github.com/Itz-Pixel-Dev/agentfarm.git

# Navigate to the project directory
cd agentfarm

# Open the application in your default browser
# On Linux
xdg-open index.html
# On macOS
open index.html
# On Windows
start index.html
```

## Usage

1. **View Agents**: The dashboard displays all available agents with their status (active/inactive).
2. **Create an Agent**: Click the "Add New Agent" button and fill out the form.
3. **Start/Stop an Agent**: Click the "Start" or "Stop" button on an individual agent card.
4. **Start/Stop All Agents**: Use the "Start All Agents" or "Stop All Agents" buttons at the top of the dashboard.
5. **Delete an Agent**: Click the "Delete" button on an agent card.

## Project Structure

- `index.html`: The main HTML file that defines the structure of the application
- `styles.css`: Contains all the styling for the application
- `script.js`: Implements the functionality of the application
